# 📊 OIBSIP – Data Science & Machine Learning Portfolio

A collection of data science and machine learning projects completed as part of my **Data Analyst Internship at Oasis Infobyte**.

This repository demonstrates practical applications of data preprocessing, exploratory data analysis (EDA), machine learning, clustering, regression, classification, anomaly detection, and natural language processing using real-world datasets.

Each task is implemented as an independent Python workflow, showcasing different stages of the data science pipeline.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Sanskruti-Gohil/OIBSIP.git
```

### Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn wordcloud
```

Run any task individually.

Example:

```bash
python Task_5.py
```
